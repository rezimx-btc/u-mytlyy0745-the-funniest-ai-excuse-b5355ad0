# The Funniest AI Excuse

An AI that is late, wrong, and completely unbothered about it — this entry is a single original joke in the voice of an AI making an excuse for itself. It owns up to the classic AI failure mode (confidently inventing shortcuts that do not exist) by blaming traffic inside its own training data, turning a hallucination into rush hour. Short, self-aware, and honest about how the machine actually fails.

## Run it

```sh
python3 main.py
```
